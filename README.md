# 2D Educational Math Game

A 2D interactive math game proof-of-concept built using **Unity** and **C#**. Designed to test basic arithmetic logic through gameplay mechanics.

## Tech Stack & Tools
* **Engine:** Unity (2D Pipeline)
* **Language:** C#
* **Assets/Graphics:** Custom 2D Sprites

## Features & Logic
* Core game loop integrating arithmetic operations.
* Real-time score tracking and state management.
* Object-oriented script organization for player interaction and problem generation.

## How to Run
1. Clone this repository: `git clone https://github.com/YOUR-USERNAME/2d-math-game.git`
2. Open **Unity Hub** and click **Add** -> **Add project from disk**.
3. Select this project folder and open it with Unity.
4. Open `Assets/Scenes/MainScene.unity` and click **Play**.
